# 桌面端完整交付设计文档

日期：2026-06-04

## 背景

项目的早期设计文档提出了技术社区的完整能力：发布、评论、搜索、收藏、点赞、关注、通知、私信、举报、审核和后台管理。当前仓库已经完成注册登录、分区浏览、主题发布、主题详情和真实评论。本期目标是在不做移动端 App 的前提下，把设计文档中提到的桌面端能力补齐到课程可演示、可验证、可交付的版本。

## 目标

- 前台提供真实搜索、筛选和排序，不再只展示静态工具栏。
- 主题支持编辑、点赞、收藏、举报和管理状态入口。
- 用户支持关注、个人主页、通知和一对一私信。
- 后台提供真实仪表盘、举报处理、用户管理、分区管理、标签管理和审核操作。
- 数据库包含对应业务模型、迁移和演示数据。
- README 明确说明项目结构、初始化数据库、演示账号、功能边界和验收命令。
- 所有功能保持 GitHub 风格开发者社区 UI，移动端专门适配不作为本期交付要求。

## 非目标

- 不开发独立移动端 App。
- 不接入 Elasticsearch、Meilisearch 或第三方推送服务。
- 不实现复杂富文本编辑器、附件真实上传和生产级通知推送。
- 不实现实时聊天和 WebSocket。
- 不实现复杂推荐算法，热度和统计使用数据库计数或演示数据。

## 交付范围

### 用户前台

- 首页和分区页支持关键词、标签、状态和排序筛选。
- 主题详情展示真实评论、真实评论数、点赞数和收藏状态。
- 登录用户可以点赞、收藏、关注作者、举报主题、编辑自己的主题。
- 用户个人主页展示资料、主题、评论、收藏和关注概览。
- 通知页展示评论、点赞、关注、举报处理和审核结果通知。
- 私信页支持一对一会话列表和发送消息。
- 标签页和成员页成为真实页面，展示标签统计和活跃成员。

### 管理后台

- 仪表盘展示用户数、主题数、评论数、举报数和近期待办。
- 内容审核支持隐藏、恢复、置顶、取消置顶、锁定、解锁主题。
- 举报处理支持查看举报、标记已处理、记录处理结果。
- 用户管理支持禁言、封禁、恢复、角色调整。
- 分区管理支持创建、编辑、关闭和重新开放分区。
- 标签管理支持查看标签统计、合并或禁用标签的演示级流程。

### 后端 API

- 继续复用 HttpOnly Cookie 会话。
- 普通用户接口覆盖搜索、互动、关注、通知、私信、举报和个人主页。
- 管理后台接口使用角色校验，管理员可执行全站治理操作，版主可处理内容类操作。
- 写操作使用 Zod schema 校验，并返回共享 DTO。

### 数据库

新增或扩展模型：

- `Thread`：增加 `isPinned`、`isLocked`、`viewCount`。
- `Comment`：支持顶层评论和 `parentId` 结构，本期页面优先展示顶层评论。
- `Reaction`：记录主题点赞。
- `Bookmark`：记录主题收藏。
- `Follow`：记录用户关注用户。
- `Notification`：记录站内通知。
- `Conversation` 和 `Message`：记录一对一私信。
- `Report`：记录主题或评论举报。
- `AuditLog`：记录后台处理动作。
- `Tag`：记录标签统计和状态。

## 设计取舍

- 标签继续保留在线程 `tags: string[]` 中，同时新增 `Tag` 表用于统计和后台管理，避免一次性重构历史主题数据。
- 搜索第一版使用 PostgreSQL/Prisma 可维护查询，覆盖标题、正文、标签和作者名；不引入外部搜索引擎。
- 附件模型和 MinIO 保留在初始化和文档中，前台只做资源扩展说明，不在本期实现真实上传 UI。
- 管理后台优先实现可演示的核心治理流程，不追求生产级复杂权限矩阵。
- 移动端响应式细节不作为验收项，但桌面和平板宽度不能出现明显布局破损。

## 验收标准

- `pnpm db:migrate` 能创建完整 schema。
- `pnpm db:seed` 和演示 SQL 能写入用户、分区、主题、评论、标签、通知、举报、私信和互动数据。
- 前台可以完成注册、登录、发帖、编辑、评论、搜索、筛选、点赞、收藏、关注、举报、查看通知和发送私信。
- 后台可以查看统计、处理举报、管理主题状态、管理用户状态和查看分区/标签。
- 所有新增 API 有 e2e 或 focused tests 覆盖关键路径。
- `pnpm test`、`pnpm typecheck`、`pnpm build`、`pnpm lint` 作为最终验证命令。
- README 覆盖项目说明、启动步骤、初始化数据库、演示账号、API 摘要、功能说明和验收流程。
